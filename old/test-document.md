## Installation

Simply download and run.

### System Requirements

- macOS 14 or later
- Apple Silicon or Intel processor

## Usage

Open any .md file with Mark.

### Keyboard Shortcuts

- Cmd+Q: Quit
- Click headings in TOC to jump to sections
