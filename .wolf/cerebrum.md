## Key Learnings

- **Design system**: Warm/crafted Notion-iA Writer aesthetic. Tokens: `--paper:#fbfaf7`, `--accent:#c2683f` (clay), `--ink:#272320`, `--surface:#f3f1eb`. Dark mode: `--paper:#1b1815`. Fonts: Hanken Grotesk (UI), Newsreader (reading), JetBrains Mono (code).
- **Tauri titlebar layout**: `titleBarStyle:"Transparent"` does NOT extend the webview under the native titlebar — must use `"Overlay"` (fullSizeContentView). `trafficLightPosition` in tauri.conf.json (Tauri ≥2.10) requires Overlay + decorations:true.
- **tao trafficLightPosition y-offset quirk**: tao's `inset_traffic_lights` resizes the titlebar container to `button_height + y` but doesn't reset the button's y-origin inside it (~9pt), so visual top ≈ config_y − 9. For buttons (14pt tall) centered in a 46px titlebar: config y:25 → visual top 16pt, center 23pt. x maps directly (x:13 → left edge 13pt). Web titlebar needs `padding-left:13px` + `52px` traffic-spacer (3×12 + 2×8 gaps).
- **Sidebar collapse pattern**: Keep sidebar mounted always; animate CSS `width` between `sidebarWidth`px and `0px` via inline style + `overflow:hidden`. Use `$state({showTOC: false})` — sidebar **starts collapsed**.
- **Inline search**: Search moved from toggled overlay into always-visible titlebar pill. `⌘F` focuses the input; `⌘P` opens QuickOpen; `⌘O` opens the file dialog (Tauri API).
- **Playwright key names**: Use `'Meta+Backslash'` not `'Meta+\\'` for the backslash key. Quick-open shortcut is `Meta+p`, not `Meta+o`.
- **uiState initial state**: `showTOC: false` — sidebar starts collapsed. Playwright tests must account for this: first toggle expands, second collapses.

- **Project:** Mark — markdown reader, rebuilt with Tauri v2 + Svelte (was native SwiftUI, moved to old/)
- **Tauri v2 + SvelteKit**: `create-tauri-app --template svelte` gives SvelteKit (not plain Svelte). Uses adapter-static for SPA. This is fine for Tauri.
- **Svelte 5 runes**: Stores use `.svelte.js` files with `$state()`. Components use `$props()`, `$derived()`, `$effect()`.
- **Tauri overlay titlebar**: Set `titleBarStyle: "Overlay"`, `hiddenTitle: true`, `trafficLightPosition: {x, y}` in tauri.conf.json. Need a `data-tauri-drag-region` div for window dragging.
- **Tauri plugins (v2)**: Install both npm package AND Rust crate. Register in `src-tauri/src/lib.rs` with `.plugin()`. Define permissions in `capabilities/default.json`.
- **Heading extraction**: Stack-based algorithm ported from Swift. Line-by-line parse of `#` headings, build hierarchy via stack pop/push.
- **Search highlighting**: DOM TreeWalker to find text nodes, wrap matches in `<mark>` elements. Safer than regex on HTML strings.
- **Markdown rendering**: `marked` library with custom heading renderer to add `id` attributes for scroll-to-anchor.
- **Tauri v2 fs scope**: `fs:read-all` enables the command but does NOT allow all paths. Must add `{ "path": "/**" }` to `fs:scope` allow list in capabilities for a file reader app.
- **Tauri CLI tool pattern**: Use `std::env::args()` in Rust `run()`, store in `Mutex<Option<String>>` state, expose via `get_pending_file` command. Frontend calls `invoke('get_pending_file')` on mount.
- **Svelte 5 `<svelte:self>` deprecated**: Use self-import (`import HeadingRow from './HeadingRow.svelte'`) instead.
- **Titlebar drag region blocks clicks**: Fixed div with `data-tauri-drag-region` at z-index 100 intercepts clicks on elements below it. Move interactive elements (search bar) to bottom of content area.
- **CSS box-sizing in flex layouts**: When using `height: 100%` + `padding-top`, must add `box-sizing: border-box` or the padding overflows and clips bottom content.

- **VS Code theme import**: No syntax highlighter is wired in (code blocks use only `--code-bg`/`--code-ink`; `--tok-*` vars are largely unused). So the *visible* effect of importing a VS Code theme is mapping its workbench `colors` (editor.background→--paper, editor.foreground→--ink, sideBar.background→--surface, textLink.foreground/button.background→--accent, etc.) onto the app palette. `tokenColors`→`--tok-*` is mapped too for forward-compat. Parser in `src/lib/utils/vscodeTheme.js`; bundled real themes in `src/lib/themes/presets.js` (Dracula/Nord/Solarized Light). Applied as inline custom props on `documentElement` (inline beats `[data-theme]` stylesheet rules); an active theme also drives effectiveTheme=theme.type. Derive `--accent-soft`/`--accent-line` via color-mix from the imported accent or they keep the hardcoded clay.
- **Theme picker is a dropdown** (`SettingsDialog.svelte`): A single "Editor theme" `<select>` (the old "Appearance" row was merged in) with two optgroups — **Built-in**: Light / Dark / System (ids `light`/`dark`/`system` → `settings.theme`, vscodeTheme cleared), and **VS Code themes**: the bundled presets (`preset:<name>`) plus an `imported` entry when a non-preset theme is active — and an **Import…** button beside it. `currentThemeId` (derived) reflects the active selection; `selectTheme(id)` dispatches. System still uses `resolveTheme(systemDark)` + the matchMedia listener in `+page.svelte`. Playwright drives it with `select[aria-label="Editor theme"]` + `selectOption('dark'|'preset:Dracula'|…)`.
- **Whole-codebase review fixes (2026-06-09)**: A Fable subagent review surfaced 23 findings; the bounded/high-value ones are fixed: link-click interception in `MarkdownViewer` (external→plugin-opener `openUrl`, `#`→scroll, relative→`onopenrelative`→`handleRelativeLink` resolves vs current dir), frontmatter only triggers on a real `---\n…\n---` block with a `key:` first line (no leading-thematic-break false positive), inline-math currency heuristic (`$5 and $10` stays text), search highlights track the `matches` array + `html` (survive doc swaps with equal match counts), error HTML escaped before `{@html}`, file-changed watcher ignores stale paths, `openByPath` stops the old watch, `⌘A` bails in editable fields, Edit menu has Undo/Redo/Cut/Copy/Paste/Select-All, `uninstall_cli` removes all targets, clipboard `.catch`, mermaid pre skipped in copy-button injection, dead code removed, fs scope adds `/tmp`+`/private/tmp`+hidden-dir globs. e2e in `tests/review.spec.js` (uses `window.__markTest.loadContent`). **Deferred (larger/риск):** image asset-protocol+CSP, bundling fonts locally, search-count-from-DOM rewrite, heading-extraction-from-marked-lexer, CLI `-w` forwarding (open consumes `-w`; needs IPC for running instance — risks the working file-open path).
- **In-app "Open Folder"**: Folder mode is no longer CLI-only. Rust `read_directory(path)` command (thin wrapper over `resolve_directory`, returns `Vec<String>`, empty when no md files). Frontend `openFolderDialog()` in fileHandler.js uses `open({ directory: true })`; `handleOpenFolder()` in +page.svelte lists via the command, sets `directoryFiles`, switches to the Files tab, opens the first file. UI surfaces: empty-state "Open Folder" ghost button, File-menu "Open Folder… (⇧⌘O)", and the `⌘O`/`⇧⌘O` keydown (note: use `e.key.toLowerCase()==='o'` because Shift makes `e.key` uppercase 'O'). `openByPath(filePath)` consolidates the read→open→catch used by the tree, quick-open, and folder-first-file, and sets `openError` (a dismissible toast in the reader) instead of silently swallowing read failures.
- **Tauri dialog auto-scopes picked paths**: The fs capability scope is static `$HOME/**`, BUT the dialog plugin auto-grants read access to any path the user picks in the native open dialog. So in-app "Open Folder" works for folders OUTSIDE $HOME (verified opening /tmp). The fs-scope limitation (bug-113) therefore only bites **CLI-passed** directories outside $HOME, not dialog-picked ones.
- **File tree explorer**: `resolve_directory` (Rust) now walks recursively (depth/count caps, skips hidden/node_modules/target/.git). Frontend `buildFileTree` turns the flat absolute-path list into a nested tree; the deepest shared directory becomes BOTH the uppercase section header AND the expandable top folder node (matches mockup). Recursive rendering via `FileTreeNode.svelte` (self-import), folders-first alphabetical sort.
- **DEV-only test hook**: The Files tree is fed by a Tauri command unavailable in a plain browser, so Playwright can't reach it normally. `+page.svelte` exposes `window.__markTest.loadDirectory(paths)` gated by `import.meta.env.DEV` (true under `vite dev`/Playwright, false in Tauri release) so e2e tests can inject sample paths and screenshot the real tree.
- **Design handoff bundle**: The Claude Design URL (`api.anthropic.com/v1/design/h/...`) returns a **gzipped tar**, not HTML — WebFetch shows it as binary. Extract with `tar xzf <saved .bin>`. Contents: `mark/README.md` (agent instructions), `mark/chats/*.md` (the iteration transcript — read it, intent lives there), `mark/project/Mark.html` + `app/*.jsx` + `styles.css` (the prototype). README says implement pixel-accurately in the target tech, and "don't render in a browser unless asked." The Mark design = the warm/clay system already in the app; the new piece is the Files tree.
- **Tree caret must match TOC caret** (explicit design requirement from the chat): both panes use icon `chevDown` = `m6 9 6 6 6-6` (down) with `.collapsed`→`rotate(-90deg)` (points right when collapsed). Folders swap `folder`↔`folderOpen` icon; files use `fileMd` (doc + md squiggle); all tree icons are `--ink-3` (NOT accent), accent only on the active file row (`.tree-row.on`). Matches `FileTreeNode.svelte`.
- **Computer-use verification of the Tauri app**: A bare `target/debug/mark` binary launched from the terminal has no proper bundle id, so the computer-use screenshot compositor (which filters to the granted `com.mark.app`) EXCLUDES its window — you see only the desktop even though the window is on-screen. Fix: build a real bundle with `npm run tauri build -- --debug --bundles app` → `target/debug/bundle/macos/Mark.app` (bundle id `com.mark.app`), then `open <that>.app --args <dir>`. Also kill the stale installed `/Applications/Mark.app` (same bundle id) first or `open_application "Mark"` focuses IT, not your build. Directory mode is CLI-only: pass a directory path as a positional arg.

## Do-Not-Repeat

- [2026-06-09] **Titlebar IS serif, but tuned** (final): The user wants the titlebar title in Newsreader serif (confirmed). The earlier serif/15px felt too big and mis-centered. Final tuned values in `+page.svelte`: `.tb-title` font-family Newsreader serif, **font-size 14px**, `line-height: 1`, `transform: translateY(1px)` (serif caps sit high in the line box — nudge down to optically center with the 28px icon buttons); `.tb-file` font-size 13px; `.traffic-spacer` width **58px** (was 52 — the gap between native traffic lights and the sidebar-toggle was too tight). Verified in the real app via computer-use. Don't flip the titlebar to sans.

- [2026-04-18] **CSS child vs sibling selectors**: When injecting DOM elements as siblings (e.g., copy button next to `<pre>` inside a wrapper), the hover selector must target the common parent (`.wrapper:hover .btn`), NOT the sibling (`pre:hover .btn`). Also, for non-scrolling overlays on scrollable content, use `position: absolute` on the wrapper (not `sticky` inside flex).
- [2026-04-19] **Tauri event listeners in onMount async IIFEs**: Declare ALL unlisten variables in the outer synchronous scope (alongside `let unlistenPromise = null`), not inside the async IIFE. Only variables declared in the outer scope are reachable by the cleanup `return () => {...}`.
- [2026-04-19] **Mermaid DOM replacement and theme re-render**: `renderMermaid()` replaces `<pre>` blocks with `<div>` wrappers — they're gone after first render. Calling `renderMermaid()` again on theme change is a no-op. Store source text in a `Map<Element, string>` keyed on the wrapper div; use a separate `rerenderMermaidTheme()` function that updates `wrapper.innerHTML` in-place.
- [2026-04-19] **Stdin temp file sentinel**: The CLI pipe script uses `mktemp /tmp/mark_stdin_XXXXXX.md`. The guard `filePath !== 'stdin'` does nothing — the real path is the mktemp output. Match on `basename.startsWith('mark_stdin_')` instead.
- [2026-04-19] **Rust watcher state on failure**: Store new state only AFTER all fallible operations succeed. In `start_watch`, call `debouncer.watcher().watch()` before `*guard = Some(debouncer)` so a failed watch doesn't leave the state holding an empty debouncer.

- [2026-06-09] **Playwright getByRole name matching is substring by default**: Adding a "Solarized Light" theme chip broke the existing `getByRole('button', { name: 'Light' })` test (strict-mode: 2 matches — "Light" and "Solarized Light"). Use `{ name: 'Light', exact: true }` when a label is a substring of another visible control.
- [2026-06-09] **JSONC trailing-comma stripping must be string-aware**: A global `text.replace(/,(\s*[}\]])/g,'$1')` over comment-stripped text corrupts string values containing `,]` or `,}`. Strip the trailing comma inside the char-by-char loop, only when outside a string, right before emitting `}`/`]`. (bug-112)

- [2026-06-10] **System theme must call `setTheme(null)`, not a concrete mode**: For the "System" theme option, `getCurrentWindow().setTheme(...)` must be passed `null` so the OS drives the webview and `prefers-color-scheme` keeps tracking the real system appearance. Passing a resolved `'light'`/`'dark'` (even the one computed from `matchMedia`) FORCES the webview theme, which freezes `prefers-color-scheme` and breaks System from following OS changes. In `+page.svelte`: `setTheme((!vscodeTheme && theme==='system') ? null : effectiveTheme)`. Verified live by toggling macOS dark mode via `osascript ... set dark mode to true/false`. e2e uses Playwright `page.emulateMedia({ colorScheme })`.

## Decision Log

- **macOS Traffic Light Inlining (2026-04-10)**: `.hiddenTitleBar` keeps traffic lights in system z-order (70pt offset from content). To truly inline them like Notes.app, use `NSWindowStyleMask.fullSizeContentView + titlebarAppearsTransparent + titleVisibility.hidden` via AppKit config. Minimal integration (window setup only), not ongoing AppKit usage.
- **Tauri + Svelte Rebuild (2026-04-13)**: User decided to rebuild from SwiftUI to Tauri v2 + Svelte. Reason: Claude is much stronger with web technologies than native macOS/SwiftUI, enabling faster iteration. All Swift code moved to `old/` for reference.
